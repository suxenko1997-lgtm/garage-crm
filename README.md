# СТО CRM — личное приложение для двоих

Это готовый проект. Ничего не продаётся, ничего не публикуется в App Store /
Microsoft Store — просто сайт, который вы откроете на своих телефонах и
добавите на главный экран. Данные общие и синхронизируются между вами и
вашим парнем в реальном времени через бесплатный Firebase.

Шагов много, но каждый — просто "нажать кнопку / скопировать значение".
Займёт минут 20–25 в первый раз.

---

## Шаг 1. Создать бесплатный проект Firebase (база данных)

1. Откройте https://console.firebase.google.com и войдите с Google-аккаунтом.
2. "Add project" → введите любое имя (например `sto-crm`) → Continue →
   можно отключить Google Analytics (не нужен) → Create project.
3. В левом меню откройте **Build → Authentication** → кнопка "Get started".
   На вкладке "Sign-in method" включите **Anonymous** (просто переключатель
   в положение On) → Save.
   (Это даёт вам с парнем доступ без паролей — оба входят "анонимно",
   но доступ к базе всё равно закрыт правилами на следующем шаге.)
4. В левом меню откройте **Build → Firestore Database** → "Create database"
   → выберите любой регион (ближайший к вам) → режим **Start in production
   mode** → Enable.
5. Откройте вкладку **Rules** внутри Firestore Database, удалите весь текст
   и вставьте содержимое файла `firestore.rules` из этого проекта → Publish.

## Шаг 2. Получить ключи конфигурации

1. В Firebase Console нажмите на шестерёнку рядом с "Project Overview" →
   **Project settings**.
2. Внизу раздела "Your apps" нажмите иконку `</>` (Web app) → дайте любое
   имя → Register app (Firebase Hosting не подключать — просто продолжить).
3. Вам покажут объект `firebaseConfig` — скопируйте его.
4. Откройте файл `src/firebase.js` в этом проекте и вставьте свои значения
   вместо `"ВАШ_API_KEY"`, `"ВАШ_ПРОЕКТ"` и т.д.

## Шаг 3. Выложить сайт (бесплатно, через Vercel)

Понадобится аккаунт на https://github.com и https://vercel.com (можно войти
через GitHub-аккаунт, регистрация бесплатна).

1. Создайте новый пустой репозиторий на GitHub (например `sto-crm`).
2. Загрузите туда все файлы из этой папки — проще всего через
   github.com: "Add file" → "Upload files" → перетащить всю папку
   (включая скрытые файлы, если есть) → Commit changes.
3. Зайдите на https://vercel.com → "Add New..." → "Project" →
   выберите этот репозиторий → Vercel сам определит, что это Vite-проект
   → просто нажмите "Deploy".
4. Через минуту получите ссылку вида `https://sto-crm-xxxx.vercel.app` —
   это и есть ваше приложение. Отправьте эту же ссылку своему парню.

## Шаг 4. Установить на телефон

**iPhone (Safari):**
Откройте ссылку → кнопка "Поделиться" (квадрат со стрелкой вверх) →
"На экран «Домой»" → Добавить.

**Android / Windows (Chrome или Edge):**
Откройте ссылку → в адресной строке появится иконка "Установить
приложение" (или через меню ⋮ → "Установить приложение" / "Install app")
→ Установить.

Готово — на обоих устройствах появится иконка, приложение открывается в
своём окне без адресной строки, а все заказы/клиенты/траты видны и там,
и там одновременно.

---

## Если что-то не так

- **Белый экран / "Завантаження даних…" вечно крутится** — скорее всего
  не заполнены ключи в `src/firebase.js`, или не включён Anonymous
  sign-in (Шаг 1.3), или не опубликованы Rules (Шаг 1.5).
- **Изменения не появляются на втором телефоне** — проверьте, что оба
  устройства онлайн; наверху приложения появляется жёлтая плашка, если
  интернета нет.
- Всё бесплатно в рамках лимитов Firebase Spark plan (щедрых для двоих
  людей — там лимиты на десятки тысяч операций в день).
